# Third-party notices

Libraries shipped in the HwProbe plugin and the hwprobe CLI. Generated by `scripts/notices.py` from the projects' NuGet restore output; the plugin's list is also on its Help tab. The CLI is self-contained, so it also carries the .NET runtime ([MIT](https://spdx.org/licenses/MIT.html), https://github.com/dotnet/runtime). Assets are listed in `assets/NOTICE.md`.
